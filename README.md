# 한칸한칸

한 달 생활비를 **1칸 1만원, 반칸 5천원**으로 나눠, 쓴 만큼 카테고리 색으로 채워가는 회고용 가계부예요.
숫자 대신 색으로 보니까 이번 달 돈이 어디로 갔는지 한눈에 보여요.

👉 **열기: https://leekangeun0120.github.io/hankanbudget/**

## 폰에 앱처럼 설치하기
- 아이폰: 사파리로 위 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- 안드로이드: 크롬으로 위 주소 열기 → ⋮ 메뉴 → **홈 화면에 추가 / 앱 설치**

한 번 열어두면 인터넷이 없어도 열려요.

## 할 수 있는 것
| 기능 | 설명 |
|---|---|
| 칸 칠하기 | 칸을 한 번 누르면 반칸, 한 번 더 누르면 한 칸. 반칸 두 개를 다른 색으로 칠할 수도 있어요 |
| 금액으로 칠하기 | 금액·카테고리·메모·날짜를 적으면 자동으로 칠해져요. 반칸이 안 되는 잔돈은 모아뒀다가 차면 칠해요 |
| 예산·카테고리 설정 | 한 달 총 예산, 한 칸 금액(5천원~5만원), 카테고리 이름·색·예산을 직접 정해요 |
| 카테고리 예산 / 총액만 | 카테고리마다 예산을 정하거나, 총액만 지키는 방식 중에 골라요 |
| 비상금 칸 | 예산을 넘긴 칸은 평소엔 숨겨둔 비상금 칸에 칠해져요 |
| 이벤트비 칸판 | 이벤트비 통장에서 나간 돈은 생활비와 따로 칠해요 |
| 지출 내역 | 금액으로 적은 내역이 날짜별로 쌓여요. 지우면 칸도 같이 지워져요 |
| 무지출 달력 | 돈을 안 쓴 날을 표시해요 |
| 색깔별로 모으기 | 같은 색끼리 모아 보고, 다시 날짜순으로 되돌려요 |
| 지난달 비교 | 카테고리별로 지난달보다 늘거나 준 금액이 보여요 |
| 회고 카드 이미지 | 한 달 색칠판과 비율을 한 장 이미지로 만들어 공유해요 |
| 시트에서 가져오기 | 구글 시트·엑셀 가계부에서 줄을 복사해 붙여넣으면 한 번에 칠해져요 |

## 기록은 어디에 저장되나요?
- 기록은 **쓰는 사람의 기기(브라우저)에만** 저장돼요. 이 저장소나 서버에는 아무 기록도 올라오지 않아요.
- 그래서 서로의 가계부는 보이지 않고, PC와 폰도 자동으로 맞춰지지 않아요.
- 다른 기기로 옮기거나 백업할 때는 **설정 → 백업하고 다른 기기로 옮기기**에서 백업 글자를 복사해 두세요. (카톡 '나와의 채팅'에 붙여두면 편해요)
- 폰을 바꾸거나 브라우저 데이터를 지우면 기록이 사라지니, 가끔 백업해 두세요.

|---|---|
| `index.html` | 앱 전체 (화면·기능) |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 설치용 이름·아이콘 |

| `print/` | 인쇄용 시트 |

수정할 때는 `index.html`만 바꿔 올리면 되고, 쓰는 사람들은 앱을 다시 열면 새 버전으로 바뀌어요.
